Ribba2012: glioma growth and treatment

This model describes proliferating tissue (P), quiescent tissue (Q), damaged quiescent tissue (Qp), and effective treatment exposure (C). Their sum Pstar describes the model's tumour-size output. Drug action damages tumour tissue, followed by delayed loss or return to proliferation. It offers a compact example of a tumour shrinking after treatment and subsequently regrowing.

  • BioModels: BIOMD0000000521.
  • Publication: Ribba et al. (2012).
  • Original file: BIOMD0000000521_url.xml, SBML L2V4, downloaded 2026-11-24. No L2V5 was listed; no conversion was performed.
  • Download: https://www.ebi.ac.uk/biomodels/model/download/BIOMD0000000521?filename=BIOMD0000000521_url.xml
  • SHA-256 from BioModels: ff2f82c46bb15f07fe612f6bac2cbecd4e1108d9b2209139552f0ce38a4e3226.
  • Reference: curation_notes.txt identifies Figure 4, upper-right panel, dashed line, with mean PCV parameters from Table 1. The downloaded reference image is ../../img/ribba2012-curation.png; its axes are months and mm.
  • Baseline run: run-1.R, plotting Pstar over 0–100 months. The time and diameter labels follow the curation image and the publication's parameter units (months and mm).
  • Proposed Heta extension: retain the original SBML, add an absorption depot feeding C, or change the effective exposure decay. Inspect the existing coupling to KDE first: changing KDE also changes the damage rate in this model, so it is not an isolated PK clearance adjustment.
  • Import and simulation checked on 2026-11-24: Heta Compiler 0.12.4, DynMSR 0.1.2, mrgsolve 2.0.1, R 4.6.1; completed successfully. The unchanged source checksum still matches BioModels.

The SBML retains its embedded CC0 notice. The reference image is a BioModels curation artifact, not a result generated by our R script.

Run and outputs

run-1.R is the short article example: load the unchanged SBML, build it, simulate, and display the tumour-diameter curve. Run it from the article directory (content/sbml-models-in-r):

source('code/ribba2012/run-1.R')

run-0.R retains the full comparison, numerical convergence check, and saved outputs. From the repository root:

Rscript content/sbml-models-in-r/code/ribba2012/run-0.R

The comparison script also accepts the article or model directory as the working directory. Heta exports and compiled C++ files are generated in R's local temporary directory. Only DynMSR, mrgsolve, a compatible Heta Compiler, and the C++ build tools required by mrgsolve are needed for the R run. No Python installation is needed to use the included digitized reference CSV. The following outputs are saved by run-0.R:

  • ../../img/ribba2012-baseline.png: standalone simulation plot.
  • ../../img/ribba2012-reference-comparison.png: overlay with the reference and residuals.
  • results/baseline.csv: simulated states and total diameter on a 0.1-month grid.
  • results/reference-comparison.csv: simulation interpolated at digitized reference times and residuals.
  • results/solver-convergence.csv: per-variable maximum change with tighter solver tolerances.
  • results/summary.txt and results/sessionInfo.txt: numerical summary and environment.

The effective initial conditions are C=1, P=7.13, Q=41.2, Qp=0; there are no additional doses. Source parameters are lambda_P=0.121, k_PQ=0.00295, k_Qp_P=0.0031, delta_QP=0.0087, gamma=0.729, KDE=0.24, and K=100. The baseline uses mrgsolve's observed defaults rtol=1e-8, atol=1e-8; the convergence run uses rtol=1e-11, atol=1e-13 on the same output grid.

Reproduction result

The supplied BioModels curation curve is reproduced to raster precision without changing parameters or equations. Pstar starts at 48.33 mm, reaches a minimum of 46.523151 mm at 6.3 months on the output grid, and reaches 96.337861 mm at 100 months. Against 437 points extracted from the curation PNG, the RMSE is 0.110248 mm and the maximum absolute residual is 0.260541 mm. The vertical image scale is 0.316456 mm/pixel. Tightening solver tolerances changes Pstar by at most 4.53e-7 mm.

These diagnostics support agreement with the curation image; they are not an acceptance threshold for clinical or scientific validation. The PNG contains no original numerical time grid. digitize-reference.py (Python + Pillow) extracts blue curve pixels using explicitly documented axis calibration into reference-digitized.csv; interpolation is used to compare different time grids. Pixel rounding, line thickness, and axis calibration contribute to residuals. This is neither exact artifact equality nor a comparison with original patient measurements.

Differences from the publication

Inspection of the author-provided full text identified differences that prevent calling this a verified reproduction of the paper itself:

  • The publication's Figure 2 model has a transfer term k_PQ * P entering Q; the downloaded SBML has k_PQ alone, although it subtracts k_PQ * P from P.
  • Table 1 gives PCV k_PQ = 0.0295; the SBML has 0.00295.
  • Table 1 gives delta_QP = 0.00867; the SBML rounds this to 0.0087.
  • The paper describes resetting the virtual treatment concentration to 1 at each treatment cycle. This SBML has only C(0)=1 and exponential decay, with no repeated-dose events.

The original XML has deliberately not been repaired or tuned to improve agreement. For the article, say "reproduce the BioModels curation simulation". Reproducing a particular original-paper treatment schedule would require a separately documented scenario and reconciliation of the differences above.

Heta extension: repeated treatment cycles

index.heta includes the original SBML unchanged and adds a TimeSwitcher that adds 1 to the current C at months 2, 4, 6, 8, and 10. Together with the supplied initial C(0)=1, this gives six treatment cycles with accumulation. This differs from the paper's reset-to-1 convention. The two-month interval is an illustrative scenario, not a clinical dosing recommendation or a reproduction of patient treatment histories.

Run source('ribba2012/run-2.R') from content/sbml-models-in-r/code to compare one cycle with six cycles. The Heta project is loaded and compiled once. param(mrgs_model, repeat_cycle__active__ = 0) disables the periodic event for the baseline; setting it to 1 enables the additional cycles. The script displays exposure and total tumour diameter. A checked plot is retained in ../../img/ribba2012-repeated-cycles.png. To regenerate the saved plot, open a PNG device before sourcing the script and close it afterward.

Compilation and both simulations completed successfully with Heta Compiler 0.12.4 and the same R/package versions recorded above. The additive-cycle scenario was rerun on 2026-11-24: its minimum diameter is 34.84577 mm at 28.7 months on the 0.1-month output grid. Output at the event time itself is the pre-event value; the following output reflects the new dose. Additional cycles produce a deeper, longer decrease in total diameter, followed by regrowth after treatment stops. The original SBML/publication differences listed above still apply.
